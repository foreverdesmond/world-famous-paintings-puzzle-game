# 项目背景与设计上下文（给 AI / Codex）

> 本文件供开发与设计（含 Codex 等 AI 代理）读取，说明项目现状、素材库与待定决策点。设计时请以本文件为"基本情况"起点。

## 一句话定位

**世界名画拼图小游戏**：把世界名画做成拼图的休闲小游戏，用滑片 / 旋转 / 限时 / 步数等玩法还原名画。核心价值是「低门槛、高完成感」——快速做出能玩的作品。

## 项目状态

- **开发中（第一版）**
- 仓库：`github.com/foreverdesmond/world-famous-paintings-puzzle-game`，默认分支 `main`
- 本轮已完成 **素材库**（101 幅世界名画，公共领域/CC0）
- **下一步**：定技术栈 → 定首个可玩玩法（MVP）→ 在 Codex 搭建可玩版本

## 素材库（设计最关心的部分）

位置：`assets/paintings/`

- **共 101 幅**世界名画缩略图，命名 `作品名__画家.jpg`（例 `mona-lisa__leonardo-da-vinci.jpg`）
- **规格**：中分辨率 JPEG，长边约 **1920px**，总大小 94.3MB，单张约 0.02–2.9MB
- **许可**：100 幅 Wikimedia Commons（95 Public domain / 5 CC0）+ 1 幅 The Met（CC0）——**全部可自由商用/使用**，界面或 README 标明来源即可
- **元数据清单**：`assets/paintings/manifest.csv`
  - 字段：`title, artist, institution, licence, page_url, image_url, file, jpeg_bytes`
  - 每幅都有原始馆藏来源 + 页面链接，可直接用于展示"这件作品来自哪里/谁画的"

**覆盖的名画家/代表作**（示意，非全量）：
- 达·芬奇：蒙娜丽莎、最后的晚餐、抱银貂的女子、维特鲁威人、天使报喜
- 梵高：星夜、向日葵、鸢尾花、麦田与柏树、卧室、吃土豆的人
- 维米尔：戴珍珠耳环的少女、倒牛奶的女仆、窗前读信的少女、代尔夫特风景
- 莫奈：睡莲、印象·日出、撑阳伞的女人

## 玩法候选（待 Richy 拍板，设计可提建议）

- 经典 **N×N 滑片拼图**（数字/图片滑片）
- 旋转拼块（拼图板块需旋转到正确朝向）
- 碎片搜集 / 拖拽组合
- 限时挑战、步数/用时排行榜

## 技术栈（待定）

轻量原则：**单页可玩、无账号系统起步、可选本地进度保存**。
倾向：纯 Web 单页（HTML/CSS/JS，或轻框架）优先于移动端，待 Richy 确认。

## 待设计 / 待确认事项（Codex 输出可围绕）

1. 技术栈具体选型（纯前端 / 框架 / 是否需要构建）
2. 首个可玩玩法（MVP 最小闭环）与游戏机制
3. 图片加载/切片策略（直接用本地缩略图切 N×N，还是按需加载）
4. 界面信息架构：选画 → 开始游戏 → 玩法 → 完成反馈 → 排行榜（可选）
